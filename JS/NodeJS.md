## Установка nodeJS
Установка либо командой с официального сайта либо с установщика на этом же сайте.
По стандарту устанавливается модуль node и npm, для проверки правильности установки вводим в командную строку (лучше от имени админа и powershell, еще лучше git bash)

```bash
node -v
//версия node
npm -v
//версия npm
```

## Создание проекта node
для инициализации проекта (создания папки проекта) используется команда `npm init`, после которой будут вопросы для создания json файла конфигурации (название версия и т.д.)

### Установка доп. библиотек
Для работы с node отдельно устанавливаются модули вроде koa.
Для установки используется команда `npm install "название"`

Например: `npm install koa @koa/router koa-bodyparser`
после установки появится папка node module, и в файл конфигурации добавятся зависимости.
```json
  "dependencies": {
    "@koa/router": "^15.7.0",
    "koa": "^3.2.1",
    "koa-bodyparser": "^4.4.1"
  }
```

## Запуск проекта

Запуск происходит при помощи команды `node 'название_файла.js'` в терминал.
После удачного запуска консоль блокируется до того момента как проект не будет принудительно закрыт человеком или ошибкой.
Принудительное завершение работы команды в *любой* консоли(терминале) используется комбинация клавиш `Ctrl + c`.

### import
Для использования установленных ранее библиотек, необходимо также их импортировать внутрь файла.
```JS
import Koa from 'koa';

import BodyParser from 'koa-bodyparser';

import Router from '@koa/router';
```

для того чтобы импортировать функцию с другого файла также используется import, но уже совместно с export.
`export` - помечаются функции доступные для импортирования 
`export const getItem = (ctx) => {}`
	 так же есть конструкция 'export default' но таким образом можно передать только одну функцию.

импортируются такие файлы похожим образом:
```js
import {"Импортируемая_функция"} from "./путь/до_файла.js" //если мы используем просто экспорт. в фигурных скобках можно указывать несколько названий импортируемых файлов через запятую
import Переменная from "./путь/до_файла.js"// при использовании default, cоответственно передастся только помеченая default функция
```

## Работа с подключенными библиотеками
 Поскольку мы подключили библиотеки с классами, нужно создать экземпляры классов, так например:
 ```js
const koa = new Koa();
const router = new Router();
 ```

чтобы была возможность включить проект необходимо открыть порт по которому можно пройти на сайт, (localhost:порт) для этого пишем 
```js
koa.listen(3000); // в скобках конкретный порт по которому можно будет найти сайт
```

```js
router.get('/', getItem, updatetItem, createItem, deleteItem);
// подключение конкретных функций к роутеру

koa.use(router.routes());
koa.use(router.allowedMethods());
//вызов всех подключенных к прослушиванию функций

koa.use(BodyParser());
//это кстати активация третей установленной библиотеки, позволяющей парсить данные с body
```
