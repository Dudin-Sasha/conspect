стратегическое проектирование определяет общую структуру системы, описывает из каких элементов состоит доменная модель внутри конкретного ограниченного контекста.

Основные элементы:
- **entity** - объект предметной области который определяется собственной идентичностью и жизненным циклом, у сущности есть уникальный ID позволяющий отличить её от других объектов даже в случае полного совпадения характеристик.
- **aggregate root**
- **aggregate** - группа связанных объектов доменной модели объединённой общей границей согласованности, позволяет контролировать состояние нескольких связанных объектов и защищать бизнес правила , главная задачи агрегата обеспечение выполнения ограничений (инвариантов).
- **value object** - объект который определяется значениями своих атрибутов, а не ID
- **repository** - паттерн который предоставляет интерфейс для получения и сохранения агрегатов, репозиторий скрывает технические детали хранения данных.
- **factory** - фабрики это паттерн создания сложных доменных объектов, используется тогда когда создание объекта, требует нескольких операций, проверок или формирования начального состояния (например создание заказа может включать проверку входных позиций, формирования снимков цен, создания ID, проверка допустимого состава заказа, и установка начального состояния)
- **domain service**
- **domain event**
- **invariant** - правило которое должно  оставаться истинным при любом допустимом изменении состояния объектов
